# Medtech Reviewer System

A desktop-based **Medical Technology Reviewer System** developed using VB.NET and Microsoft Access. The application is designed to help Medical Technology students review important topics through an interactive question-and-answer system.

## 📚 Features

* Interactive reviewer games
* Multiple-choice questions
* Answer selection and validation
* Score tracking
* Question navigation
* Organized review content
* Database-driven questions and answers
* User-friendly desktop interface

## 🛠️ Technologies Used

* **VB.NET**
* **Microsoft Access**
* **Windows Forms**

## 📌 Project Overview

The Medtech Reviewer System is a desktop application created to provide students with an interactive way to review Medical Technology-related topics.

The system stores reviewer questions and answers in a Microsoft Access database and uses VB.NET to handle the application's interface, user interactions, answer validation, and scoring.

## 👩‍💻 My Role

Designed and developed the application's user interface and implemented the core functionality using VB.NET. I also created and managed the Microsoft Access database used to store the review questions, answers, and related information.

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/K-mariedizon/Medtech-Reviewer-System.git
   ```

2. Open the project in **Visual Studio**.

3. Make sure the required VB.NET and Microsoft Access components are installed.

4. Verify that the database connection points to the included Access database.

5. Build and run the application.
